# Phase Reports

Each development phase gets its own report in this folder once the phase is merged. A report records:
- what the phase delivered;
- the commit for each task;
- how it was reviewed;
- the decisions made along the way;
- known limitations;
- what comes next.

| 3 — Server deploy | (written at phase end) | In progress on `phase-3-deploy` |

**Conventions** (spec §11b):
- Name each report `phase-<id>-report.md`.
- Write it after the phase's final review is clean, and commit it to `main` together with the merge.
